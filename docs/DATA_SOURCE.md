# 数据来源与运行模式

## 数据范围

项目包含两种明确区分的运行模式。两者复用相同的工程接口，但数据来源、使用目的和可得出的结论不同。

| 项目 | Research Mode | Demo Mode |
|---|---|---|
| 用途 | 本地量化研究与实验复现 | 公开页面、数据库和流程演示 |
| 行情来源 | Tushare Pro API | 确定性合成数据 |
| 股票范围 | 研究时间段内获取的沪深 300 成分股范围 | 生成的资产标识，不映射真实证券 |
| 频率 | 日频 OHLCV | 日频 OHLCV 结构的模拟记录 |
| 凭证 | 用户自行提供 `TUSHARE_TOKEN` | 不需要凭证 |
| 公开内容 | 文档和脱敏结果摘要 | 合成数据、Demo 数据库和聚合结果 |

## Research Mode

### 主要数据来源

本地研究以 **Tushare Pro API** 为主要数据来源，使用日频开盘价、最高价、最低价、收盘价、成交量和成交额。项目保留了 AKShare/Sina 增量更新工具，但它们属于单独标记的补充路径，不改变正式研究快照的数据来源说明。

### 股票范围

研究目标范围为所选时间段内的沪深 300 成分股。本地验收快照包含 364 个股票标识，因为研究文件跨越多个成分日期并保留了本地已有历史。当前仓库没有完整的历史成分变更表，因此股票池时点一致性和幸存者偏差仍属于研究限制。

### 数据流程

```text
Tushare Pro API
       ↓
Raw 日频 OHLCV
       ↓
字段标准化与数据质量检查
       ↓
Clean 行情数据
       ↓
技术因子与下一交易日标签
       ↓
按时间切分的模型验证
       ↓
T日信号 / T+1开盘回测
```

### 获取与公开边界

- 用户需要通过环境变量 `TUSHARE_TOKEN` 提供自己的 Tushare Pro Token。
- 仓库不保存真实 Token，也不会从已提交配置中读取真实凭证。
- 原始行情、完整研究数据库、模型权重、逐行预测和每日持仓不上传 GitHub。
- 受数据接口限制、数据使用条款和文件规模影响，项目不公开分发原始行情。
- 仓库只保留脱敏汇总指标，便于核对文档中的研究结论。

## Demo Mode

Demo Mode 使用固定随机种子生成 OHLCV 结构的数据和合成资产信息，每条生成记录都带有合成来源标记。仓库中的 Demo SQLite 数据库用于复现查询和 10 个 Streamlit 页面，不需要数据源凭证。

公开页面中的 5,200 个资产是合成标识，不应理解为 5,200 只真实 A 股行情。模型和回测页面展示本地研究流程生成的脱敏摘要，不是使用合成 Dashboard 数据重新训练得到的结果。

## 复现边界

新用户可以通过 `make demo` 或 `bash run_demo.sh` 复现 Demo Mode。若要复现正式研究指标，还需要相同的数据权限、提取时间、股票范围、本地模型依赖和实验配置。仓库会说明这些条件，但不能公开底层真实行情。
