# 项目设计说明

## 1. 项目目的

量化研究中，数据准备、模型实验和交易执行之间经常存在口径不一致。例如，模型评价可能使用随机切分，回测可能使用信号生成时尚不可获得的价格，或者没有计入交易成本。本项目把这些环节放在一条可检查的流程中，用于展示完整的数据分析方法。

项目不以高收益率作为成立条件。当前模型只有较弱的样本外区分能力，策略在计入成本后也没有跑赢沪深 300 基准，这些结果均如实保留。

## 2. 研究问题

本项目的主要问题是：

> 日频价格、趋势、动量、波动率和成交量特征，是否包含足够的样本外信息来判断下一交易日涨跌；这些信号在可执行时序和交易成本下能否转化为策略结果？

主要预测任务是下一交易日涨跌分类。收益回归和稳定盈利不属于当前实验目标。

## 3. 流程设计

本地研究流程包含五个边界：

1. **Raw**：保留接近数据源结构的日频行情，便于追溯。
2. **Clean**：统一日期和字段，处理重复记录，并记录缺失值与 OHLCV 异常。
3. **Processed**：按时间顺序计算技术因子和下一交易日标签。
4. **Experiment**：让两个模型使用相同股票池、特征、时间边界和评价指标。
5. **Execution**：把样本外概率输入 T+1 开盘回测，显式计算交易成本。

公开展示流程使用确定性合成数据代替受限制的真实行情，只发布脱敏研究摘要，不在 Streamlit 进程中重新训练模型。

## 4. 模型选择

### 为什么使用 XGBoost

XGBoost 适合处理表格型金融特征，能够表达非线性关系和特征交互，不要求统一缩放全部输入，并能输出特征重要性。当前策略使用 XGBoost 的样本外上涨概率进行排序。

### 为什么使用 BiLSTM

BiLSTM 作为序列模型对照，输入 20 日特征窗口，用于检查短期时间上下文是否能提供额外信息。它与 XGBoost 使用相同的 21 个输入字段和最终测试目标。为了适配普通笔记本，本地训练对训练序列进行了固定规则的数量限制，这一点作为实验限制保留。

两个模型用于比较已有的两种建模方式。当前研究问题不需要继续增加模型复杂度。

## 5. 验证方式

随机划分可能让较晚市场阶段的信息进入较早样本，从而高估泛化能力。因此，项目按信号日期排序，使用 70%/15%/15% 的训练、验证和测试时间切分，并剔除标签跨越分区边界的信号日。

评价指标同时包含 Accuracy、AUC、Precision、Recall 和 F1。当前 AUC 和 Accuracy 接近 0.5，应解释为信号较弱，不能描述为成功的预测系统。

## 6. 回测设计

信号在 T 日收盘后才能得到，因此 `next_open_v2` 在 T+1 开盘执行，并至少跨交易日持有。成本与约束包括：

- 买卖双边 0.03% 佣金；
- 卖出单边 0.05% 印花税；
- 买卖各 0.10% 固定滑点；
- 缺少开盘价、停牌、显式不可交易标记和已有涨跌停字段的阻塞记录；
- 换手率、最大回撤、Sharpe、基准和成交统计。

日频弱信号可能被高换手和成本抵消，因此交易成本是研究问题的一部分，不会为了改善最终结果而调整。

## 7. 已知限制

- 沪深 300 历史成分信息不完整，存在股票池选择和幸存者偏差风险。
- 复权、退市、停牌和每日涨跌停字段并未覆盖全部日期。
- 固定滑点只是近似，不能模拟盘口深度和市场冲击。
- 日频技术特征没有覆盖基本面、日内数据和已核验的另类数据。
- 公开仓库不包含受限制的行情和模型权重，复现正式指标需要原始本地研究输入。
- BiLSTM 训练集为了适应本地硬件进行了确定性抽样。
- 当前模型没有证明稳定预测能力，回测也没有获得超额收益。

这是一个个人数据分析与研究项目，不是实盘交易系统，不构成投资建议。
