# Quant Data Platform UI Architecture Refactor

日期：2026-09-15  
范围：仅调整现有 Streamlit Dashboard 的展示层与信息层级。

## 1. 页面架构变化

页面统一为三层：

```text
结论层 → 核心分析 → 详细研究
```

首屏优先呈现页面标题、定位说明、3～5 个核心指标和 1～2 个主要图表；详细表格、日志、参数和次要图表通过 `st.expander` 查看。该调整帮助普通用户先理解结论，同时保留专业用户需要的证据。

现有研究链路在页面上按以下顺序表达：

```text
数据工程层 → 数据分析层 → 因子研究层 → 机器学习层 → 策略研究层 → Streamlit 展示层
```

## 2. Sidebar 调整

保留原有单一页面导航和十个 route，只增加视觉分组：

- **DATA ENGINEERING**：数据平台、数据洞察
- **MARKET ANALYSIS**：市场总览、股票画像、行业分析、情绪分析
- **FACTOR & ML RESEARCH**：因子研究、模型验证
- **STRATEGY RESEARCH**：策略回测
- **SYSTEM**：系统概览

分组通过 Sidebar 标题和说明呈现，不改变页面跳转逻辑，也没有增加或删除页面。

## 3. 每个页面的展示逻辑

所有指标和图表均来自既有查询及结果文件；“核心解读”只对已有指标作客观转述，不引入新的研究方法或因果判断。

## 4. 保留的数据能力

- 保留本地真实研究数据与公开确定性合成 Demo 的分离；
- 保留 Raw-Clean-Processed 数据分层、质量状态、字段诊断和数据血缘；
- 保留 21 个正式模型输入技术因子、XGBoost/BiLSTM 实验及当前评价指标；
- 保留 `next_open_v2` 的 T 日信号、T+1 开盘执行、佣金、印花税、滑点、换手、成交和阻塞信息；
- 保留公开服务库的有界查询、缓存、行业聚合、因子 IC 和情绪来源字段；
- 保留旧口径的防误用提示和 `legacy_unknown` 等数据质量信息。

本次未修改数据采集、清洗、数据库结构、因子计算、模型训练/推理、模型结果、回测逻辑、成本模型或任何研究指标计算。
