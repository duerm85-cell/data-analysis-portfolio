# 数据质量说明

当前质量报告为 `WARN`，不是 `FAIL`。报告的失败条件包括重复主键、非法日期、非法 OHLC、非正价格、负成交量、非法股票代码和未声明的意外缺失；这些当前为 0。

## 为什么是 WARN

- 滚动因子在每只股票历史开始阶段没有足够窗口，因此 5/10/20/60 日收益、动量等字段会结构性缺失。
- 每只股票最后一个交易日没有下一交易日，因而没有 `label`。这是标签定义导致的末端缺失。
- 报告记录了极端收益变化，当前快照为 89 条。它们可能来自真实市场跳变、复权或数据源差异，需要人工核验，不能静默删除。

## 可以接受的缺失

结构性窗口缺失和末端标签缺失可以接受，前提是进入训练或分析前按任务需要剔除，并在报告中保留数量、比例和原因。公开 Demo 当前主要只有末端标签缺失。

## 需要改进的部分

应继续核验极端收益的复权与跨源口径，监控零成交量和异常日期；对来源为 `legacy_unknown` 的情绪记录保持隔离。质量页面展示的是数据状态，不等于所有数据都适合直接建模。
